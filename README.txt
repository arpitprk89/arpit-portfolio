ARPIT PAREEK — CURRENT PORTFOLIO

Files
- index.html: complete responsive portfolio page
- assets/arpit-portrait.jpg: portrait used on the page

To update a GitHub Pages site
1. Download and extract arpit-portfolio-current.zip.
2. Open the existing portfolio repository on GitHub.
3. Upload index.html to the repository root and choose to replace the old file.
4. Upload the assets folder with arpit-portrait.jpg, keeping the folder name exactly "assets".
5. Commit the changes. GitHub Pages may take a little time to publish the update.

Notes
- The project links and contact links are included in index.html.
- The contact section uses a mailto link, so there is no non-functional backend form.
- Google Fonts are loaded from Google; system fallback fonts will be used if they cannot load.
- Edit the HTML directly to change descriptions, links, or section copy.
